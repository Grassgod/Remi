# MUL-395 S9-5 A：Chat 列表批量权限读取

250会话 fixture 的整个请求从1253条SQL减为4条；以下全部实测请求满足 SQL≤20、阻塞≤30ms。用户侧响应容器、字段和过滤/排序不变。

## 实现与语义

兼容 `/api/chat/sessions` 和原生 `/api/multiremi/chats` 共享批量读取：SQL NOT EXISTS排除两类Feishu transport会话，Agent轻量字段一次批量读，工作区/creator/Agent权限在原口径下过滤。store 默认列表仍不排除transport，只有这两个Web列表显式启用。Chat投影保留serializer使用的全部列、原未读相关子查询与240字符最后消息；省去未使用列和逐会话 full Agent/skills读取，没有搬运prompt/技能正文。

新增 `chat-sessions-batch.test.ts` 将旧逐会话鉴权路径作为reference，比较原生/兼容全部JSON字段和顺序，覆盖default/all/archived、pinned、私有Agent；同时检查≤20SQL、一次Agent表读取、无skills正文查询。既有隔离/transport/store测试回归，PG与SQLite结果见C报告验证表。

## 同口径与复跑

before 是同步 main 后的 `2d6bb2d9b3acd177d16ffa35a6780e1cd0a4a5d7`；after 是本次 Draft PR 的 A/B/C 实现组合（交付评论给完整 head/tree）。A `6853f09f`、B `986b14f1` 各自单独提交，C 单独提交。未混入后续 main 收益。

本地 PostgreSQL 18.4、Bun 1.3.14，专用隔离实例；每个版本/规模各建独立临时库并最终删除。固定 250 Chats、20 Agents（每个 skill 正文16 KiB）、10 runtimes、每条新增 usage 约480 bytes、每个 runtime 一个 running 任务，其余新增任务 completed。新增任务为5000/10000/20000，加公共 fixture 的257条，实际任务为5257/10257/20257。身份为本地合成 PAT/updater 身份。不是209数据，也不代表生产 p95；未访问209。

使用同一 `tests/manual/bench-mul395-s9-5.ts` 的桥计数和采样算法，默认串行路由顺序 Chat→runtimes→execution-groups→models→heartbeat。每路由 sample0 留作首次读；预热5次后正式20次。p50/p95只取正式20次（nearest rank），最大值包含全部26次，原始 JSON 保留每轮。共享 usage 缓存跨路由生效，因此默认样本只有 runtimes 的 sample0 是空列表 usage 缓存；其他路径首读不能冒充空 usage 缓存。额外 `MUL395_USAGE_CASES=1` 隔离测空缓存/失效；`MUL395_HEARTBEAT_CASES=1` 隔离测到点/发版忙/版本变化。

`db_queries/db_ms/bridge_bytes` 是 PostgresSyncDatabase 的进程计数差，db_ms 为实际同步桥 Atomics.wait 累计；bytes含每次桥回复，并非浏览器响应大小。工具代理统计最大单条桥回复。`main_thread_ms` 是请求期间反复调度0ms timer 的最大间隔，记录最长不能让出主线程的区间，包含 timer 调度底噪；不以 HTTP总耗时或 db_ms冒充阻塞。`non_db_ms = elapsed_ms - db_ms`，包含 JS、JSON、鉴权与调度；初始化/预处理不计入。测量期间保留实际墙钟，不把不同初始化生成的ID/时间戳或响应 hash当成功能等价证据；语义对拍来自独立定向用例。串行测量，不并行启动本次其他 benchmark；局部共享主机调度噪声不删除、不事后扣除。

复跑时仅通过子进程环境配置 `MULTIREMI_TEST_POSTGRES_URL`（一次性PG），先清除 `MULTIREMI_TOKEN`：`env -u MULTIREMI_TOKEN bun run tests/manual/bench-mul395-s9-5.ts --out <path>`。规模由 `MUL395_TASKS`指定。显式PG不可达即失败，不回落SQLite；报告不含连接配置。工具 SHA256：`68f8f76c4144abed3eb34dd712064bd6b5cf98bd8ea48c86111d3d2a8a286f93`。

原始：`MUL-395-s9-5-{before,after}-{5000,10000,20000}.json`，已移出仓库，见 MUL-395 评论 `cmt_r8mv3dq7r416` 附件 `MUL-395-s9-5-raw-json-5660f6b1.zip`（取自 `5660f6b1`，附逐文件 sha256 清单）。
